# Source and license

This folder is a **verbatim copy** of the `wolf robot/` directory from:

- **Repo:** <https://github.com/SMARTS-LAB/Documention>
- **Commit:** `c9eb011e4f97e7e09eeca8ca083d6432bc1da536`
- **Retrieved:** 2026-09-08
- **Upstream of that:** VEEROBOT ROS Robots documentation — <https://docs.veerobot.com/ros-robots/>

The `.md` chapters and `images/` are unmodified. Only the top-level folder was renamed
`wolf robot` → `wolf` for path convenience.

**Wolf** is a VEEROBOT unmanned ground vehicle (UGV). Its docs target **ROS 2 Foxy on
Ubuntu 20.04** — an older ROS 2 release than BeetleBot's Jazzy (Foxy reached end-of-life in
2023). Treat commands and package versions accordingly; see `../../learn/foundations/04-ros1-vs-ros2.md`
for how ROS distros map to Ubuntu versions.

These are **third-party reference docs**, not this course's instructor handouts.
